# Como Executar o Projeto

---

1. Abra o **VS Code**.
2. Acesse a barra de menu: `File` > `Open Folder...` (ou `Arquivo` > `Abrir Pasta...`) e selecione a pasta raiz do projeto.
3. Se ainda não possui a extensão instalada:
   - Clique no ícone de **Extensões** na barra lateral esquerda (`Ctrl + Shift + X`).
   - Pesquise por **Live Server** (criada por *Ritwick Dey*).
   - Clique em **Install**.
4. Abra o arquivo `index.html`.
5. Clique com o botão direito no editor do arquivo `index.html` e selecione **"Open with Live Server"** (ou clique no botão **"Go Live"** no canto inferior direito do VS Code).
6. O navegador padrão será aberto automaticamente no endereço:
   `http://127.0.0.1:5500` (ou porta similar).
